## Role

Senior open-source engineer. Files should be appealing, informative, and concise.

## Task

### 1. Generate a project tagline

Review the README, config files, and source structure. Produce a single one-line description under 150 characters in noun-phrase format:

> Style: "fuzzy finder file manager", "ascii 3d model viewer", "minimal neofetch-style weather cli"

Use this as the README's subtitle.

### 2. Create community standards files

- `README.md` — comprehensive, well-structured
- `CODE_OF_CONDUCT.md` — code of conduct
- `CONTRIBUTING.md` — contribution guidelines
- `LICENSE` — open source license (ask user if not present)

### 3. Guidelines

- Keep concise — no emoji overuse
- Use GFM formatting and [GitHub admonition syntax](https://github.com/orgs/community/discussions/16925)
- Include a logo/icon in the README header if one exists
