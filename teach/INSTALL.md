# Install universal Teach skill (Windows / Codex)

1. Back up `C:\Users\USER\.agents\skills\teach` if present.
2. Extract the `teach/` folder from this ZIP into `C:\Users\USER\.agents\skills\` so `C:\Users\USER\.agents\skills\teach\SKILL.md` exists.
3. Restart Codex or open a new session.
4. Test: `Use the teach skill to teach me Python functions. Explain with a small worked example, let me modify the code, then help me run and debug it. One practical step at a time.`

This is a replacement for the previous engineering-only upgrade. It preserves the supporting format files and the engineering lab playbook, and adds a universal practical playbook. It does not install itself.
